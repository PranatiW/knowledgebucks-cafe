Cloud Basics

VPC, Subnet, IP and Port

A beginner-friendly networking explanation.

VPC

A VPC is your private network inside a cloud platform. Think of it as an entire college campus.

Subnet

A subnet is a smaller section inside the VPC, similar to a department or building inside the campus.

IP Address

An IP address identifies one specific device, similar to a classroom number.

Port

A port identifies the service running on the device, like a particular door or service counter inside that classroom.
