S3 Backup, Sync and Restore

Why backup?

Backup protects important files if the original folder is deleted or damaged.

Why sync?

The sync command transfers only new or modified files, making repeated backups efficient.

Why RestoreData?

RestoreData is a separate local folder used to download and verify the files stored in S3.

aws s3 sync BackupData s3://your-bucket/
aws s3 sync s3://your-bucket/ RestoreData/
