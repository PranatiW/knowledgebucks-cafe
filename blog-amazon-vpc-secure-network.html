Inside an Amazon VPC: Designing a Secure Cloud Network

A Virtual Private Cloud gives an organisation a logically isolated network in which cloud resources can communicate under controlled rules.

The VPC is the network boundary

A VPC defines an address range and becomes the networking space for resources such as virtual machines, databases and load balancers. It allows architects to decide which systems may communicate internally and which systems may be reachable from outside.

Subnets separate responsibilities

Subnets divide the VPC into smaller network segments. Public-facing components may be placed in public subnets, while databases and internal services are commonly placed in private subnets. This separation reduces exposure and makes traffic control easier to understand.

Route tables decide where traffic goes

A route table contains rules that direct traffic toward local networks, gateways or other destinations. A subnet does not become public merely because it has a public IP address; it must also have an appropriate route to an internet gateway.

Security groups and network ACLs serve different purposes

Security groups are attached to resources and control allowed traffic. Network ACLs operate at the subnet boundary. Using both without understanding their roles can create confusing behaviour, so rules should remain simple, documented and intentional.

Public and private do not mean safe and unsafe

A public subnet is not automatically insecure, and a private subnet is not automatically secure. Security depends on routing, access rules, application configuration, identity controls, patching and monitoring.

A sensible three-tier design

  • A public load balancer receives user requests
  • Application servers run in private subnets
  • A database remains isolated from direct internet access
  • Monitoring and logging provide visibility into network activity

The architectural lesson

A well-designed VPC limits unnecessary communication. Instead of asking, “How do I make everything connect?”, a better question is, “Which exact communication paths are required for this application to work?”
